# ShotClip 0.4.0：离线批量素材理解

## 本版范围

面向长演讲、现身说法素材，先建立可恢复、可检索、可回看原片的本地文稿库。
保留原有 Shotcut 剪辑、导出和 0.3.0 Agent 方案确认机制，不自动修改时间线。

- 批量导入视频/音频，或递归导入文件夹。支持 MP4、MOV、MKV、AVI、WebM、MP3、WAV、AAC、FLAC、M4A。
- 文件夹分批入库，支持暂停；再次导入同一文件夹会去重。扫描队列本身不跨重启恢复，已入库任务可以恢复。
- FFprobe 读取时长、分辨率和音轨；无音轨素材明确标记，不调用转录。
- FFmpeg 每次提取最多五分钟的单声道 16 kHz PCM，Whisper 顺序转录，避免一次解码整个长视频。
- 每段转录后原子保存；暂停、重启后从最后成功分段继续，未完成的当前分段重新计算。
- 查看完整文稿、跨素材关键词搜索（最多 500 条）、双击句子定位原始素材。
- 选中素材后“加入播放列表”，随后拖入时间线，沿用 Shotcut 的撤销、剪辑与导出。
- 失败项单独显示错误，可重试；GPU 转录失败自动尝试 CPU；每个子进程阶段限制为 30 分钟。

## 使用流程

1. 启动 ShotClip，在顶部工具栏或“视图”菜单打开“素材理解”。面板默认收起，可浮动。
2. 在 Agent 的本地模型设置中选择 Whisper `.bin` 模型及运行引擎；Windows 安装版沿用内置引擎路径检测。
3. 在“素材理解”导入文件或文件夹，点击“开始 / 继续”。本功能只需要 Whisper，不需要启动 llama.cpp 或 Ollama。
4. 分析完成后输入原话关键词，双击结果定位原片；或选择素材点击“查看完整文稿”。文稿窗口是打开时的快照。
5. 把合适素材加入播放列表，拖入时间线进行剪辑。0.3.0 Agent 仍只对当前时间线提出受控修改建议。

## 数据与安全

索引位于应用数据目录的 `media-library-v1/index.json`，遵循 `--appdata` 设置，跨项目共享，不复制原视频。
该路径由操作系统决定；Windows 通常在用户本地应用数据目录，macOS 通常在 Application Support。
索引包含本机素材绝对路径、元数据、转录文本、原素材时间戳、稳定 ID、已完成进度及模型指纹。
这些内容可能涉及敏感信息；本版缓存**未加密**，部署时应配置操作系统账号与磁盘访问权限。

文件指纹使用规范路径、大小与修改时间的 SHA-256，不是整文件内容哈希；移动文件会视为新素材，
保留大小与修改时间的原地修改不能可靠检测。定位和未完成任务启动前检查文件指纹。
更换模型后重新转录，避免混用两种模型文稿。尚无重新定位、缓存管理和全文语义向量检索 UI。

QSaveFile 原子写入，QLockFile 防止两个实例同时写同一索引；损坏/不兼容的索引不覆盖。
出错时先备份索引，再人工修复或移走损坏索引并重启。失败子进程的末尾错误文本保留在本地任务记录。
临时音频和 SRT 位于系统临时目录，正常完成、暂停或退出时删除；强制终止可能留下临时目录。
所有新分析操作均调用本地子进程，无 HTTP 请求，不向外发送素材、文稿或路径。

## 开发与验证

在已满足 Qt、MLT 等原生构建依赖的 macOS 开发环境：

```sh
cmake -S . -B build/shotclip-debug -G Ninja \
  -DCMAKE_BUILD_TYPE=Debug -DCMAKE_PREFIX_PATH=/opt/homebrew \
  -DSHOTCUT_VERSION=0.4.0 -DSHOTCLIP_VERSION=0.4.0 \
  -DSHOTCUT_BUILD_TESTS=ON -DCLANG_FORMAT=OFF
cmake --build build/shotclip-debug -j 8
ctest --test-dir build/shotclip-debug --output-on-failure
open build/shotclip-debug/src/ShotClip.app
```

测试覆盖 SRT 时间戳/越界/重叠校验、缓存读写/锁/损坏保护、重复导入、缺少引擎，以及
真实 FFmpeg/FFprobe 提取中文路径 302 秒临时音频、模拟 Whisper 子进程、300 秒检查点暂停、
重启继续、复用缓存、更换模型失效和原素材变化拒绝。测试临时素材自动清理，不提交媒体。
模拟 Whisper 只验证进程和数据闭环，**不等于真实模型准确率、CUDA/Vulkan 或长演讲实测**。
POSIX 模拟子进程集成用例在 Windows 跳过，其余缓存和解析用例可跨平台运行。

2026-09-09 本地验证：macOS arm64 / Qt 6.11.1，0.4.0 原生编译成功，CTest 7/7 通过；
素材库测试自身 8/8（含初始化与清理），没有跳过。使用独立 `build/shotclip-040-smoke`
配置启动，日志确认 0.4.0、Metal 和主窗口初始化。界面自动检查服务超时，尚未完成逐项点击验收。

Windows 工作流 `.github/workflows/build-windows.yml` 已更新版本为 0.4.0，通过 GitHub Actions
手动运行 `build-shotclip-windows` 生成安装 EXE。构建依赖与打包流程沿用 0.3.0。
本地已有的 0.3.0 EXE 不是本版本；未经新的 Windows 构建不能当作 0.4.0 分发。

真实 Windows 验收仍需：安装/卸载、无开发环境启动、中文目录批量导入、Whisper 真模型 CPU/GPU
运行、暂停重启恢复、文稿定位、加入播放列表、拖入时间线与最终 MP4 导出。
